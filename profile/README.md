We build tools for people who run their own machines: one panel for a fleet of Linux servers, and a proxy that keeps AI coding tools from wasting tokens.

## Projects

| Project | What it does | Status |
|---|---|---|
| [**Omynix**](https://github.com/Optivail/Omynix) | One panel for all your Linux servers: fleet overview, metrics and alerts, Docker, intrusion prevention, backups, and certificate monitoring. A small outbound-only agent runs on each machine. | Coming soon. The agent and Shield code will be published here. |
| [**Gatekeep**](https://github.com/Optivail/Gatekeep) | A self-hosted proxy for AI coding CLIs such as Claude Code, Cursor and Codex. Point the tool at Gatekeep once and it compresses the traffic, with a live dashboard of the tokens saved. | Available, AGPL-3.0. |
